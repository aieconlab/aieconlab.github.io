  ‘7,000억 달러 가까이’도 ‘7,000억 달러 넘게’로 정합화.
- ‘현지 보도들의 일치된 추정’ → ‘복수 보도의 추정’으로 완화, ‘집행이 멈춘 사이’ →
  ‘올해 상반기 집행이 0인 가운데’로 정밀화.
- 2025년 설비투자 교차검증 표기를 ‘분기 합’ → ‘상반기 누계+Q3+Q4’로 정확화.
- 1·2차 교정 기록에 후속 정정 사실을 주석으로 연결(자사주 ‘당시 미확인’, ‘총설비투자’ 재명시).
