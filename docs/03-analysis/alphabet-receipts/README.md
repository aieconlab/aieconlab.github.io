주의해 걸러낸 것들:
- ‘Anthropic 몸값 3배’ 표현(일부 보도) → 3,800→9,650억은 약 2.5배이므로 배수 표현 대신 금액으로 표기.
- 순이익에는 현금이 따라오지 않는 평가이익이 대부분 → ‘사상 최대 이익’은 항상 착시 단서와 함께 서술.
- ‘조정 EPS 2.62달러(1센트 미달)’ 보도(TechTimes)는 평가이익 조정 범위가 다른 집계와 상충 → 본문에서 특정 조정 EPS 값을 단정하지 않고 ‘예상을 크게 벗어나지 않는 수준’으로 서술.
- ATM 프로그램(400억 달러 한도)은 사용 목적이 임직원 주식보상 세금 납부로 명시 → 설비투자 재원으로 오인될 수 있어 본문에서 제외.
- ‘14개월 만의 최대 하락’(Schaeffer's)은 장중(eyes) 표현 → 종가 기준 확인 불가로 미사용.
