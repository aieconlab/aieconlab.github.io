### 검산

`extract_bea.py`와 그림 2·3은 BEA 공표치와 대조하는 `assert`를 포함한다. 그림 1은 BEA 자료를
쓰지 않고 SK하이닉스 정성 표현에서 만든 구간과 산식을 검사한다. 커버 스크립트도 표시값을
`bea_extract.csv`에서 계산해 대조하며, 이와 별도로 레이아웃 침범 검사를 수행한다.
원천 SHA 검사는 `assert`가 아니라 명시적 예외로 구현해 `python -O`에서도 살아 있다. 스크립트가 오류 없이 끝나면 아래가 확인된 것이다.

- 정보처리장비 실질 증가율 2026Q2 = 8.3%, 2026Q1 = 39.9% (표 1.5.1 공표치)
- 명목 증가율(필자 계산) 2026Q2 = 22.5%, 2026Q1 = 50.8%
- 두 값의 산술 차이 = 14.2%포인트
- 가격지수 전년 동기 대비 2026Q2 = +7.37%, 이보다 높은 분기는 4개이고 가장 최근은 1975Q2
- 1983Q2~2021Q3의 154개 분기는 모두 전년 동기 대비 하락
- 그림 1의 몫이 D램 74.7~80.0%, 낸드 74.4~77.2% 구간 안
- `extract_bea.py`: 원천 워크북의 SHA-256이 위 대장과 같은지, 2026Q2 반영본
  ("Data published July 30, 2026")인지, 그리고 GDP 1.5/2.1, `Y034RY` 0.19/0.77,
  `Y001RY` 0.48/0.74, `Y034RL` 8.3/39.9, `A021RY` -1.51의 9건이 공표치와 일치하는지
- `fig02`: 가격 연율 2026Q1 7.8%·2026Q2 13.1%, 명목 배수 = 실질 배수 x 가격 배수 항등식,
  로그 가격 몫 60.7%
- `fig03`: 원천 워크북 SHA-256이 대장과 같은지, y축이 전 관측치를 담는지
  (최저 1998Q4 -13.836%로 절단 금지)
- `make_cover`: 표시값을 CSV에서 계산해 22.5/8.3/0.77/0.19와 대조

## 3. 본문 수치의 계산 기준

| 본문 수치 | 계산 |
|---|---|
| 기여 0.67%p (2026Q2) | 표 1.5.2의 `Y034RY`(0.19) + `Y001RY`(0.48) |
| 기여 1.51%p (2026Q1) | 같은 방법: 0.77 + 0.74. column4가 인용한 '약 1.5%p'와 같은 기준 |
| 명목 22.5% | 표 1.5.5 `Y034RC` 수준에서 (당분기/전분기)^4 − 1 |
| 가격 연율 13.1% | 표 1.5.4 `Y034RG`에서 직접 계산. 명목 배수 = 실질 배수 x 가격 배수 항등식으로 교차검산 |
| 명목 증가의 약 60% | ln(1.131) / ln(1.225) = 60.7% (실질 39.3%). `fig02`가 자료에서 계산·assert |
| 가격지수 YoY +7.4% | 표 1.5.4 `Y034RG`(2017=100)에서 전년 동기 대비 |
| D램 ASP 몫 약 77% | 매출 배수 = ASP 배수 x 출하량 배수. ln(1.30) / [ln(1.30) + ln(1.08)]. 구간은 ASP 29~31%·출하 7~9% |
| 낸드 ASP 몫 약 76% | ln(1.55) / [ln(1.55) + ln(1.15)]. 구간은 ASP 54~56%·출하 14~16% |
| 수입 기여 -1.51%p | 표 1.5.2 `A021RY`. **모든 수입**의 기여이며 자본재만의 값이 아니다 |

## 4. 한계 (본문에도 명시한 것)

- 미국 GDP는 **속보치**다. 2026-08-26 2차 추정, 2026-09-30 3차 추정에서 개정되며
  기업이익 계정은 이 회차에 포함되지 않는다.
- 정보처리장비·지식재산생산물은 AI와 무관한 컴퓨터·소프트웨어·연구개발 지출을 포함하는
  광의의 근사이고, 데이터센터 건설 같은 구조물 투자는 포함하지 않는다.
- 개별 기업의 설비투자를 국민계정에서 식별할 수 없다. 하이퍼스케일러의 지출 가운데 얼마가
  SK하이닉스 매출이 됐는지도 BEA 통계와 각 사 공시 어디에서도 확인되지 않는다.
- 수입 자본재 구입액은 미국 국내 투자에 포함되고 수입 항목에서 상계된다. 따라서 수입은
  투자 기여 하락의 원인이 아니라 GDP 산정의 별도 경로다.
- ASP와 개당 단가는 제품 구성 변화를 포함하므로 순수한 가격 인상분과 분리되지 않는다.
- SK하이닉스의 ASP·출하량 증가율은 회사가 **정성 표현**으로만 제시했다. 그림 1은 점추정이
  아니라 구간이며, 구간 설정은 필자의 해석이다.
- 마이크로소프트의 분기는 FY2026 4분기(2026년 4~6월)로 알파벳·메타의 2026년 2분기와
  대상 기간은 같지만 명칭이 다르다. 세 회사의 설비투자는 정의가 달라 합산하지 않았다.
- 마이크로소프트의 '설비투자'는 한 회사 안에서도 두 정의가 쓰인다. 실적 설명회의 분기
  410억 달러는 금융리스 56억 달러를 포함하고, 현금흐름표의 유형자산 취득액은 358억 200만
  달러다. 약 1,750억 달러는 **달력연도 2026년** 조정치이지 FY2027 전망이 아니다.
