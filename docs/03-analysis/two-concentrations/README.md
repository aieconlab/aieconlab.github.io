## 상태

**이 패키지는 게시본이다.** 수치는 2026-08-03 저녁(KST) 웹 조사와 외부 검토로
확인했다 — 수치·출처는 1~7라운드에서 교차 확인했고, 8라운드부터는 문서·게시 패키지의
정합성을 재검토했다. 그림은 `data/`의 CSV에서 재현된다. **제3자 저작물의 전문 사본
4건은 재배포 조건 문제로 로컬 전용 `data/raw-local/`(git 제외)에 보존하고, 공개
저장소에는 URL·취득일시·SHA-256·검증 메모를 담은 `data/raw/PROVENANCE.md`만 둔다.**
산업통상부 HWP·PDF 첨부 원본 확보는 비차단 아카이브 과제다(TODO 1).

## 구성

- `data/monthly_semiconductor_exports.csv`: 2025-07~2026-07 월별 총수출·반도체 수출액
  (산업통상부 각 월 '수출입 동향' 통관 잠정치. 출처 URL 열 포함). 비중은 스크립트가 계산.
- `data/cap_share_milestones.csv`: 삼성전자+SK하이닉스의 코스피 시총 비중 이정표 12개
  (언론이 한국거래소 집계를 전재한 날짜별 값. basis 열이 보통주 기준 판정 방식).
- `data/raw/PROVENANCE.md`: 원자료 출처·검증 대장(공개판) — 자료별 URL·취득일시·
  SHA-256·확인 내용·공개 제외 사유. 제3자 저작물 전문 사본 4건(국민연금 2024년도
  기금운용보고서 PDF, KRX 밸류업 보도자료 PDF, 산업부 게시 페이지 HTML, 뉴스핌
  마감기사 HTML)은 재배포 조건이 확인되지 않아 `data/raw-local/`(git 제외,
  `data/.gitignore`)에 로컬 보존한다. 로컬 폴더의 `SHA256SUMS`가 대장과 같은 해시를 담는다.
- `scripts/fig01_export_share.py` → `out/fig01_export_share.png` (게시본: `static/images/post/trend19/`)
- `scripts/fig02_cap_share.py` → `out/fig02_cap_share.png` (게시본: 동일)
- `scripts/make_cover.py` → `out/trend19_cover.png` (게시본: `assets/images/post/trend19_cover.png`)
- 인터프리터: `/opt/anaconda3/bin/python3` (matplotlib 3.10.6), 폰트 Apple SD Gothic Neo.
  `savefig(metadata={"Date": None})`.
