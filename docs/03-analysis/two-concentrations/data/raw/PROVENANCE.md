# 원자료 출처·검증 대장 (공개판)

제3자 저작물의 전문 사본은 재배포 조건이 확인되지 않아 **공개 저장소에 포함하지 않는다.**
사본 원본은 로컬 전용 폴더 `../raw-local/`(git 제외, `data/.gitignore`)에 보존하며,
여기에는 각 자료의 URL·취득일시·SHA-256 해시·검증 내용만 기록한다. 아래 해시와
로컬 사본의 `SHA256SUMS`는 동일하다.

산업통상부 첨부(HWP·PDF)의 개별 공공누리 이용표시는 미확인 상태다. 산업통상부
[저작권정책](https://www.motir.go.kr/kor/contents/81)은 공공누리 표시가 부착된
저작물인지 확인하고 미부착 자료는 사전 협의하도록 안내하므로, **원본 확보 후 허용
조건을 확인해 공개 보존 여부를 결정한다.**

취득 방법은 모두 curl 또는 브라우저 없는 HTTP 요청이고, 최초 HTTP 취득 일시(KST, 파일 생성 시각과 구분되는 원 요청 시각)는 항목별로 적었다.
