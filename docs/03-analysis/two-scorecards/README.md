## 재현 순서

1. `data/` 의 CSV가 원자료 사본이다. 다시 받으려면 위 URL 패턴으로 내려받고 `_fetch_log.txt`의 SHA-256과 대조한다(FRED는 개정 반영 시 값이 바뀌므로, 대조는 같은 빈티지끼리만 성립).
2. `/opt/anaconda3/bin/python3 scripts/verify_claims.py` 실행. 본문이 '재계산'으로 표기한 수치와 보조 수치(실업자 수 등)를 합쳐 46건을 data/ 사본만으로 다시 계산해 PASS/FAIL을 출력한다(전부 PASS면 종료코드 0. 2026-08-09 실행 결과 46건 전부 PASS).
3. `/opt/anaconda3/bin/python3 scripts/make_figs.py` 실행. 본문 그림 3종은 `static/images/post/two_scorecards/`(관례: 본문 그림은 static)에, 표지는 `assets/images/post/trend20_cover.png`(표지는 assets)에 생성한다. 파일명은 본문 그림 번호와 일치한다(fig01_productivity=그림 1, fig02_payrolls=그림 2, fig03_laborshare=그림 3). `savefig(metadata={"Date": None})`로 바이트 재현성을 유지한다(동일 머신·스택 기준).

## 검증 범위

- FRED 반영치는 BLS 공표치와 동일 원천이며, 본문이 '재계산'으로 표기한 수치 전체는 scripts/verify_claims.py가 data/ 사본만으로 자동 재현한다. 발표문에만 있는 수치는 아래 수동 대조 범위에 있고 스크립트 대상이 아니다.
- BLS 발표문 원문(USDL-26-1290 생산성, USDL-26-1291 고용) 텍스트는 bls.gov가 자동화 접근을 차단하므로 2026-08-08 밤 브라우저에서 수동 대조했다. 발표문에서 확인한 수치(5·6월 하향 수정 폭, 12개월 평균 +34,000(이 값은 verify_claims.py로도 재현된다), 헬스케어 +22,000·평균 +36,000, 금융 정점 대비 -121,000, 노동분배율 52.9%, 순환 연율 2.1%/1.5%/2.1%, 8/28 예비 벤치마크 공지, 9/4·9/3 다음 일정)는 이 대조에서 확인했다.
- 검수 반영 라운드(2026-08-09)에서 추가로 수동 대조: ①기술주석의 월간 증감 약식 90% 오차한계 ±122,000 ②표 B-4의 민간 전체 총주당노동시간지수 116.7(2026년 5·6·7월 보합) ③1분기 수정 이력(5/7 예비 0.8% → 6/4 수정 0.3% → 8/6 재수정 0.8%, USDL-26-0686·26-0785) ④로이터 전재 원문의 AI 서술이 '이미 나타난 효과'가 아니라 '향후 기대'임(whtc.com 본문 직접 확인, 전문 사본은 저작권 관례상 미보존). ⑤BLS 생산성 발표 일정 페이지에서 2분기 수정치 2026-09-03, 3분기 예비치 2026-11-05 확인.
- 시장 예상치와 발표 당일 논평(로이터 전재·CNBC·악시오스·HR 다이브·SHRM·하이어링 랩)은 보도 귀속으로만 인용했다. CNBC의 다우존스 집계 +83,000은 원문에서 직접 확인했다.
- 3차 검수 라운드(2026-08-09 오전)에서 추가 확인: ①설문 방법론 원문(hiringlab.org 2026-08-05 게시)에 'Indeed 후원, Pulsenomics LLC 협력, 2026년 7월 실시, 120명 응답' 명시 ②SHRM 원문의 자오 인용이 'narrowly defined tech employment'임을 확인.
